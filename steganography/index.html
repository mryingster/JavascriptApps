Steganography

Steganography is the art of hiding visual information within other visual media. This can be accomplished in many ways. In this example, you can encode or decode a hidden image in the lower bytes of another image.

Uncompressed digital images store visual information using numbers. Each pixel of an image contains a number representing the amount of red, green, and blue required to produce the desired color. Typically, these values ranges from 0 (no color) to 255 (all color). When represented in binary, there are 8 bits per color channel.

With this type of steganography, we are going to ignore the lower (least significant) bits in our image, and replace them with values from the surreptitious image we want to hide.

The values from the hidden message image have to be scaled down though to fit within the amount of bits we've dedicated to them. In this example, instead of being between 0 and 255, the values will be between 0-3 (2 bits). When the image is decoded, the values will have to be multiplied back up to make the image visible.
